# Резюме

## Описание проекта

Одностраничный сайт-резюме обо мне.

Стек:
- HTML
- CSS
- JavaScript
- Lucide Icons

## Сайт

[Открыть GitHub Pages](https://katrinhurricanegsl.github.io/resume/)

## Выполненные требования

- Семантическая HTML-разметка
- Стилизация с CSS с использованием Flex и Grid
- Фильтрация навыков по категориям
- Поиск навыков 
- Совместная работа поиска и фильтра
- Отображение сообщения "Ничего не найдено." при пустом результате 
- Переключение светлой и тёмной темы
- Адаптивная верстка
